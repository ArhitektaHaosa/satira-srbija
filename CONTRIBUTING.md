# Contributing

This repository prefers small patches that keep the satire contract intact.

- Do not add a publish path to the middleware.
- Do not emit `NewsArticle`.
- Do not weaken HTML allowlists to make a model “just work”.
- Do not commit `.env`.
- Plugin code stays PHP 8.1, WordPress coding style close enough to read.
- Python stays 3.11+, no ORM.

A change that makes a hurried reader more likely to forward a piece as news is a bug.
