# Editorial policy

This is a humor site. It is not a newsroom that sometimes jokes.

## Label

Every article, every listing card, every RSS item, every Open Graph title prefix if the theme allows it:

**SATIRA / PARODIJA**

The badge is not optional chrome. Missing badge = do not publish.

## Layers the writer must keep separate

| Layer | Meaning |
| --- | --- |
| FACT | A real event or public statement that inspired the piece. Named and, when possible, linked. |
| SATIRE | The invented escalation. |
| FICTIONAL QUOTE | A line no real person said. Set in a blockquote whose caption says it is part of the parody. |
| EDITORIAL COMMENT | The punch, not a verdict dressed as reporting. |

Never present a fictional quote as an exclusive, a leak, or a documented statement.

## Real people and firms

Allowed as targets of parody when the piece is labeled and the reader can see the hinge between fact and invention.

Not allowed:

- invented documents, stamps, or “official communiqués” that look copy-pasted from an institution
- medical, legal, or financial instructions
- content that a reasonable reader could forward as news in a family chat without noticing the label

If the hinge is thin, add `inspiration_url` and a one-line context box.

## Tone

Intelligent, deadpan, absurd, dry, occasional sysadmin / mIRC / internet humor. Balkan register is welcome. Cheap clickbait is not. A loud headline is fine if the body earns it.

Influences to study as *form*, not to clone: The Onion, ClickHole, the shorter Babylon Bee pieces, regional deadpan columns. Do not lift sentences.

## Footer

Every body ends with:

`Ovaj tekst je satira/parodija.`

If inspired by a real event:

`Inspiracija / kontekst:` plus the URL.
